5.2 Scoring (core/scorer.py)

Goal: compute a score between 0 and 100 for each candidate.

Steps:

    Compute age in hours since published_at.

    Compute:

        recency = 1.0 for brand new, fading to 0 at time_window_hours.

        engagement = combination of likes, views, and like/view ratio.

        velocity = views per hour (log-scaled).

        entity_priority = look up priority from entities.yaml, default 1.0.

        cross_platform_signal = for now, just 0 (but keep param for future).

Example scoring formula (implement something similar, configurable via settings):

python
def calculate_score(candidate, weights, entity_priority_map, cross_platform_signal=0.0) -> float:
    age_hours = max(1.0, (now - candidate.published_at).total_seconds() / 3600)

    recency = max(0.0, 1.0 - age_hours / time_window_hours)
    like_ratio = candidate.likes / candidate.views if candidate.views > 0 else 0
    engagement = min(1.0, like_ratio / 0.05)  # normalize around 5% like rate
    velocity = math.log10(max(1.0, candidate.views / age_hours))

    priority = entity_priority_map.get(candidate.entity_matched, 1.0)

    score = (
        weights["recency_weight"] * recency +
        weights["engagement_weight"] * engagement +
        weights["velocity_weight"] * velocity +
        weights["cross_platform_weight"] * cross_platform_signal +
        weights["entity_priority_weight"] * priority
    )

    # Scale to 0–100
    return max(0.0, min(100.0, score * 20))

7. Orchestration and Scheduling (main.py)

main.py should:

    Load environment variables (YOUTUBE_API_KEY, DISCORD_WEBHOOK_URL).

    Load YAML configs (entities.yaml, settings.yaml).

    Initialize:

        YouTubeClient

        Storage

        DiscordNotifier

    For each category:

        Iterate through entities and keywords.

        Call YouTube to fetch candidates within last time_window_hours.

    Filter and score all candidates.

    Rank and split by category.

    Save results to SQLite (and CSV if enabled).

    Build a Discord summary and send it.

Pseudo-flow:

python
def main():
    config = load_config()
    yt_client = YouTubeClient(api_key=os.getenv("YOUTUBE_API_KEY"))
    notifier = DiscordNotifier(webhook_url=os.getenv("DISCORD_WEBHOOK_URL"))
    storage = Storage(config.storage.sqlite_path)

    candidates = []

    for category, data in config.categories.items():
        for entity in data.entities:
            for keyword in config.keywords:
                new_candidates = yt_client.search_candidates(
                    entity=entity,
                    keyword=keyword,
                    category=category,
                    published_after=time_window_start,
                )
                candidates.extend(new_candidates)

    filtered = filter_candidates(candidates, config)
    scored = score_candidates(filtered, config)
    top_by_category = rank_by_category(scored, config)

    run_date = today()
    storage.save_run(run_date, scored)
    storage.export_csv(run_date, config.storage.csv_output_dir)

    if config.discord.enabled:
        content = notifier.build_summary_message(
            top_by_category["hip_hop"],
            top_by_category["nba"],
            top_by_category["celebrity"],
        )
        notifier.send_summary(content)
